# CycleCare V1.0

A privacy-first, mobile-first menstrual cycle and women's wellness PWA.

## V1.0
- Period and flow tracking
- Cycle-day and phase estimates
- Calendar
- Symptoms and mood
- Sleep, water and activity tracking
- Basic cycle insights
- Women's health education
- Local device storage
- Data export/delete
- Installable/offline PWA foundation

## Important
Cycle predictions are estimates, not diagnoses or guaranteed contraception. Health education is not a substitute for professional medical care.

## Publish
Upload the project files to a GitHub repository and enable GitHub Pages. Use the repository root as the Pages source.
